DASHBOARD - ENTRY ENGINE (Otomatis dari Candle)

AsetBiasEntrySLTP1TP2R:RSize / LotConfidence
---------

Cara baca: Entry = harga terakhir. SL = 1x ATR (volatilitas 20 candle). TP1 = 1.5x ATR, TP2 = 3x ATR. Untuk Gold/Forex Size = Lot. Untuk Crypto Size = koin (BTC/ETH). Untuk Saham Size = lembar saham. Confidence = skor kualitas setup, bukan jaminan profit. Harga Twelve Data adalah harga pasar umum, bisa beda 1-3 pips dari spread 【entity-JustMarkets¦canonical_name=JustMarkets】 - cek 【entity-JustMarkets¦canonical_name=JustMarkets】 sebelum eksekusi.

📈 ENTRY PLAN - SWING (H4 / H1 - Tahan 1-3 Hari)

Untuk XAUUSD / Forex / Crypto: pakai candle 4H. Untuk Saham: pakai candle 1D. SL lebih lebar, TP lebih jauh. Entry = tunggu pullback ke Entry, jangan kejar harga.

Belum ada data Swing - Tarik Candle dulu. App akan otomatis tarik candle 4H untuk Swing (atau 1D untuk Saham).

⚡ ENTRY PLAN - SCALPING (M15 / M5 / M3 - Tahan 15-60 Menit)

Untuk XAUUSD / Forex / Crypto: pakai candle 5M / 15M. Untuk Saham: pakai candle 15M. SL ketat, TP cepat. Hanya ambil jika Confidence ≥ 65% dan harga dekat Entry (max 0.5x ATR). Jangan scalping saat spread melebar / news besar.
